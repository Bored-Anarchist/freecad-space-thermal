# Q0 numerical checkpoint

Retain C++20 for the owned engine. Use pinned SUNDIALS 7.3.0 CVODE behind an FCST integration boundary, with FCST supplying thermal equations, property derivatives, algebraic elimination, control events and diagnostics. BDF is the initial stiff-integration baseline; keep Adams available for measured nonstiff workloads. Use dense linear algebra as a small-case comparison and banded direct algebra for the measured fixed-bandwidth networks. This decision authorizes implementation under WP-11; it does not expose a production solve operation.

The executable experiment is [prototypes/numerical](../../prototypes/numerical/main.cpp), built and installed by [check_numerical.py](../../tools/check_numerical.py). Its separately frozen [criteria](../../ci/numerical-criteria-v1.json) and [fixture](../../tests/fixtures/numerical/checkpoint-v1.json) declare SI equations, discretization, normalization floors, quantities, tolerances and failure categories before execution. The seed is projected from the validated WP-03 native snapshot and checked against its independently authored analytic source. The nonlinear oracle uses Python RK4, Newton algebraic elimination and event bisection; the native prototype uses CVODE, analytic Jacobians and monotone algebraic bisection. The steady oracle reduces external heat balance to a scalar equation and inverts the conductance quadratic.

The experiment compares BDF/dense, BDF/band and Adams/band at identical inputs, integration tolerances and sample times. All must pass analytic, nonlinear transient, conservation, event and restart checks. The nonlinear model has two capacitive nodes with a 100:1 capacity ratio, temperature-dependent capacities/conductance, an eliminated zero-capacity node, a prescribed boundary, radiation feedback and a hysteretic heater. Jacobians are checked by centered differences. Both steady and transient calculations execute in C++; Python prepares inputs and assesses results. An initial inconsistent heater state and malformed input fail with bounded diagnostics. A cooperative stop at 10 s returns `cancelled`; a fresh process resumes the checkpoint and must reproduce temperatures and all subsequent switches. Durable jobs, hostile checkpoint authorization and cancellation deadlines belong to WP-06.

The initial reference run observed 33 heater switches in 20 s. Maximum nonlinear temperature disagreement was approximately 4.1e-6 K for BDF and 1.3e-6 K for Adams, below the predeclared 2e-5 K limit. Both BDF linear solvers gave identical sample values. Adams needed fewer steps on this small event-heavy fixture (610 versus 1261); it is retained as a candidate. This result provides no evidence that one integrator is universally faster or more suitable for arbitrary stiff systems. BDF remains the conservative initial stiff interface choice, subject to measured production fixtures.

The scale fixture has 12 on the diagonal and -1 on five neighboring diagonals in each direction, with independently manufactured `x_i=1+i/n` and `b=A*x`. Dense and banded solvers both run at 128 nodes. Banded runs at 1,000, 10,000 and 100,000 nodes (999,970 directed links at the largest size). Every repetition checks all entries and residuals; three repetitions retain runtime ranges, medians and process peak working set. The initial 100,000-node run took about 0.02 s and 22 MB peak working set. These are fixed-bandwidth linear algebra measurements, not an arbitrary-graph product benchmark or completion of PERF-001. No dense large-network allocation is attempted.

The [reference configuration](../../ci/numerical-reference.json) freezes the actual CPU family/model, available physical RAM, OS build, single-thread setting, native compiler 19.31.31107.0, x64 dynamic CRT, CMake 3.31.6 and strict floating point. The local oracle driver records Python 3.11.3; hosted CI uses its existing locked Python 3.11.9 and records actual compiler/build information. Hosted CI runs correctness and bounded scale regressions; its hardware does not replace the frozen local performance reference. `--require-reference` rejects a mismatch. Future hardware/toolchain changes require a new reference assessment, and supported release toolchains require their later product qualification.

Windows clean-install checks copy the installed executable and its runtime DLLs away from both build trees, then execute with only that directory on PATH and without Python/host variables. The C++ executable uses no Python, FreeCAD or vendor solver. SUNDIALS source/archive/license hashes are locked in [probe-sources.json](../../ci/probe-sources.json); reused extracted source bytes are verified against that archive before building. The library is BSD-3-Clause, with its upstream attribution/license preserved in authorized local source storage. No third-party source or binary is newly published by this package. All dependency binaries and actual source hashes are recorded with each run.

Implementation effort consists of a standalone native experiment, an independent oracle/evidence module, one build/install/assessment driver, synthetic policies/fixtures and adversarial regressions. Windows integration exposed the SDK `min`/`max` macros and the older compiler's deterministic path-map prerequisite; both were corrected without loosening numerical criteria. The first compiler failure and all later attempts remain under `.local/numerical/`. Each run records actual source byte hashes, build/dependency hashes, settings, hardware, exact observations, diagnostics and artifact hashes. Bounded summaries and completion evidence link to those sealed manifests. Criteria identity is the version plus its exact SHA-256; a changed threshold creates a new attempt and cannot overwrite a failed assessment. Failed, interrupted and superseded attempts remain local. Replay verifies the manifest and all sealed artifacts and rejects missing/duplicate/nonpassed coverage.

The Monte Carlo policy predeclares 16 seeds, three sample counts, Wilson intervals at nominal 95% coverage, Bonferroni family treatment, practical error and convergence/outlier rules. It is a policy for WP-12, not a claimed radiation implementation. Freeze the benchmark quantities before executing that future ensemble; never select seeds after inspecting results.

No Rust comparison was selected. PETSc's earlier Windows packaging disposition remains unsupported under the active native MSVC profile, so it is not a measured numerical candidate here. SUNDIALS performs low-level numerics; FCST retains model semantics and does not delegate thermal solving to another thermal application. No language speed ranking follows from this checkpoint.

The acquired inventory is reconciled with the prototype's native-only scope: all 12 vendor compatibility profiles remain unqualified and every source/runtime/schema/rights gap retains its owner in [inventory/gaps.json](../../inventory/gaps.json). WP-01 acquired inventory and WP-03 native contracts remain completed. This checkpoint closes the remaining native Q0 numerical decision. General DAE/index handling (including IDA), arbitrary sparse graphs/fill, spatial meshes, production property tables, general expression events, radiation geometry, durable checkpoints, GUI integration and source comparisons remain explicit later-package obligations. None is silently represented by this reduced network experiment.
