# Optional stretch goals

## SG-PLATFORMS: macOS and Linux configurations

macOS and Linux add-on, engine, host, build and installer configurations are
uncommitted stretch goals. They have no work-package number, milestone, delivery
date, dependency or release gate. The committed project consists of Windows work
packages WP-01 through WP-21 and Windows Q0/P0/Q1/Q2 acceptance.

These ideas may be reconsidered after the Windows work, but they are not promised
follow-on delivery. Implementation requires a future scope decision. Any later
support claim would need newly selected toolchains/official FreeCAD profiles and
automated installation, GUI/CLI/MCP parity and numerical qualification.

Historical configuration references are retained in [ci/stretch](../ci/stretch/README.md).
They are inactive and create no current platform support claim or Windows blocker.
